# Instaladores de Fortuna Real

La versión estable más reciente se descarga desde
[GitHub Releases](https://github.com/OscarD0823/Fortuna-Real/releases/latest).

Opción recomendada para Windows 10/11 x64:

1. Descarga `Fortuna-Real-<versión>-Instalador.exe`.
2. Haz doble clic y sigue el asistente.
3. Abre Fortuna Real desde el escritorio o el menú Inicio.

El ZIP con el instalador es una alternativa si el navegador bloquea la descarga
directa. Los archivos `.sig` y `latest.json` pertenecen al sistema de
actualizaciones; no deben editarse.

Los binarios no se guardan dentro del historial del repositorio. Al ejecutar
`3 Ejecutar/Crear instalador Fortuna Real.cmd`, la copia local firmada se crea en
`Entrega/2 Instaladores`.
