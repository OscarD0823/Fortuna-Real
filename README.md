# Fortuna Real

Aplicación de escritorio para sorteos con una ruleta animada, selección sin
repeticiones, modo de ganador directo y modo eliminación.

## Desarrollo

```powershell
npm install
npm run dev
```

Para abrir la aplicación de escritorio se necesitan las herramientas de C++ de
Visual Studio (MSVC y Windows SDK):

```powershell
npm run tauri dev
```

## Compilación

```powershell
npm run build
npm run tauri build
```

La configuración y los participantes se guardan localmente en el equipo.
