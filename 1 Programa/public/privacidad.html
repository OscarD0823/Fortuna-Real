Privacidad y almacenamiento

Fortuna Real · actualizado el 7 de octubre de 2026.

Los nombres que agregas, la configuración y los resultados se guardan localmente en este navegador. La aplicación no envía estas listas a un servidor ni tiene cuentas, analítica propia o salas en línea en esta versión. Evita introducir información sensible y utiliza alias si compartes pantalla.

Web, Windows y conexión

La web y el programa de Windows guardan datos por separado: no se sincronizan automáticamente. Instalar la web no instala el programa de Windows ni su voz Daniela High. En la web se utilizan las voces que ofrezca el navegador, que pueden depender de Internet y del proveedor del sistema.

Después de una primera carga completa con Internet, la web intenta conservar sus recursos para abrirse sin conexión. El navegador puede borrar esa caché; no se garantiza conservación indefinida. Exporta tus resultados desde «Ver resultados». No se recarga automáticamente una partida para aplicar una versión nueva.

Servicios externos

GitHub Pages aloja la web y puede registrar datos técnicos, incluida la dirección IP, conforme a su política de privacidad. Los enlaces al repositorio y las descargas abren GitHub. La aplicación de Windows comprueba las actualizaciones en GitHub. No se comparte el historial de participantes en esas comprobaciones.

Control de tus datos

Puedes exportar una copia de los resultados. Borrar los datos del sitio desde el navegador elimina permanentemente sus listas e historial; exporta antes si deseas conservarlos. En un equipo compartido, otros usuarios de ese perfil del navegador pueden verlos.
