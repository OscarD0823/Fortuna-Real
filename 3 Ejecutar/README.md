# Ejecutar Fortuna Real

- `Iniciar Fortuna Real.cmd`: prepara lo necesario y abre el proyecto en modo
  de desarrollo.
- `Ejecutar Fortuna Real.cmd`: acceso corto al iniciador principal.
- `Instalar Fortuna Real.cmd`: instala la versión estable de `2 Instaladores`
  o actualiza la copia existente en la misma ubicación.
- `INSTALAR O ACTUALIZAR.cmd`: iniciador para paquetes compartidos; debe estar
  junto al instalador y evita crear una segunda instalación.
- `Crear instalador Fortuna Real.cmd`: valida, compila y firma la entrega local.
- `Iniciar prototipo nativo de Canicas.cmd`: abre el prototipo técnico de
  Canicas.
- `Iniciador GitHub/`: respaldo para descargar el repositorio público, el
  instalador estable y todas las dependencias en otra computadora.

Para un usuario final se recomienda el instalador de
[GitHub Releases](https://github.com/OscarD0823/Fortuna-Real/releases/latest),
no el modo de desarrollo.
